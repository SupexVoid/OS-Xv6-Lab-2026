# xv6 课程设计路线图

## 最终验收目标

1. 十个 MIT 6.S081 2021 Lab 分支均保留可解释的实现提交。
2. 每个分支运行 `make grade`，目标得分 100/100，并保存测试日期与摘要。
3. 主分支形成带阅读导航的项目报告，逐 Lab 记录目的、过程、关键代码、问题、解决方案、结果分析和个人心得。
4. 答辩前完成一次冷启动演练：启动 WSL、切换指定分支、编译并进入 xv6、运行典型命令、退出 QEMU。
5. 仓库发布到本组自己的 GitHub 地址，报告中只放托管链接，不提交源码包。

## 工作顺序

| 阶段 | Lab | 核心主题 | 验收 |
| --- | --- | --- | --- |
| 环境与入门 | util | 用户程序、进程、管道 | `make grade` |
| 系统调用 | syscall | 用户态/内核态接口、进程统计 | `make grade` |
| 虚拟内存 I | pgtbl, traps, cow | 页表、异常、写时复制 | 各分支 `make grade` |
| 并发与设备 | thread, net, lock | 线程、网卡驱动、锁竞争 | 各分支 `make grade` |
| 存储与虚拟内存 II | fs, mmap | 文件系统、映射文件 | 各分支 `make grade` |
| 交付 | main | 报告、仓库导航、答辩演练 | 提交清单复核 |

## 每个 Lab 的固定流程

1. 阅读 MIT 实验页和指定的 xv6 book 章节。
2. 从对应 MIT starter 分支开始，只修改题目要求涉及的文件。
3. 小步提交；每完成一个子任务先跑定向测试，再跑完整 `make grade`。
4. 与学长分支对照思路，不照搬报告文字；记录实现差异及其原因。
5. 把失败现象、定位过程和最终验证写入实验记录，保留少量有代表性的输出。

## 2. 第一次打开终端

在项目根目录的 PowerShell 中执行：

```powershell
git switch main
. .\xv6-env.ps1
```

注意第 2 行开头是“点、空格”。它只为当前 PowerShell 窗口配置工具链；关闭窗口后需要重新执行。

## 3. 启动任意实验

以 Lab 1 为例：

```powershell
git switch util
make clean
make qemu
```

看到以下内容表示 xv6 启动成功：

```text
xv6 kernel is booting
init: starting sh
$
```

然后在 xv6 的 `$` 后输入本页表格中的演示命令。退出 QEMU：先按 `Ctrl+A`，松开后按 `X`。

切换下一个实验前，再执行：

```powershell
git switch main
. .\xv6-env.ps1
git switch mmap
make clean
make qemu
```

实际只要不关闭 PowerShell，环境变量会一直有效，因此中间的 `git switch main` 和重新加载脚本可以省略，直接切换实验分支即可。

## 4. 最推荐的现场演示

若老师只让任选一个实验，优先演示 `mmap`：

```powershell
git switch mmap
make clean
make qemu
```

进入 xv6 后：

```text
mmaptest
```

正常结尾：

```text
mmap_test: ALL OK
fork_test OK
mmaptest: all tests succeeded
```

这个演示时间短，同时能说明系统调用、页表、缺页异常、文件系统和 `fork`，答辩展示效果最好。

## 5. 网络实验的特殊运行方式

`net` 需要两个 PowerShell 窗口。两个窗口都先加载环境：

```powershell
git switch main
. .\xv6-env.ps1
git switch net
```

窗口 1 启动主机服务器：

```powershell
make server
```

窗口 2 启动 xv6：

```powershell
make qemu
```

进入 xv6 后执行 `nettests`。若只需证明项目能运行，不建议把网络实验作为首选现场演示。

## 6. 十个 Lab 的一句话解释

1. `util`：用已有系统调用编写 Unix 用户程序，练习进程、管道和文件操作。
2. `syscall`：增加系统调用跟踪和系统资源统计，理解用户态进入内核的路径。
3. `pgtbl`：操作 RISC-V 页表，理解虚拟地址到物理地址的映射。
4. `traps`：处理系统调用、异常与定时器中断，并实现用户态 alarm。
5. `cow`：让 `fork` 先共享物理页，写入时再复制，减少无用内存拷贝。
6. `thread`：实现用户线程切换，并练习互斥锁和条件变量。
7. `net`：补全 E1000 网卡的发送和接收描述符环。
8. `lock`：拆分热点锁，提高多核内存分配和块缓存的并行度。
9. `fs`：用二级间接块支持大文件，并增加符号链接。
10. `mmap`：把文件惰性映射到进程地址空间，并在共享映射时处理写回。

## 2. 打开实验环境

在 Windows 中启动 Ubuntu 22.04 LTS，进入项目目录：

```bash
cd ~/xv6-labs-2021
git status
git branch
```

如果现场使用的目录不同，只需要把第一条命令换成实际仓库路径。

## 3. 启动任意实验

以 Lab 1 为例：

```bash
git switch util
make clean
make qemu
```

看到以下内容表示 xv6 启动成功：

```text
xv6 kernel is booting
init: starting sh
$
```

随后在 xv6 的 `$` 提示符后输入演示命令。退出 QEMU：先按 `Ctrl+A`，松开后按 `X`。

## 4. 最推荐的现场演示

若老师只要求任选一个实验，优先演示 `mmap`：

```bash
git switch mmap
make clean
make qemu
```

进入 xv6 后运行：

```text
mmaptest
```

正常结尾：

```text
mmap_test: ALL OK
fork_test OK
mmaptest: all tests succeeded
```

该实验时间较短，同时涉及系统调用、页表、缺页异常、文件系统、`fork` 和资源释放，适合作为答辩主演示。

## 5. 网络实验提示

`net` 实验需要主机端测试服务器。打开两个 Ubuntu 终端并进入仓库，然后切换到 `net` 分支：

```bash
git switch net
```

终端 1：

```bash
make server
```

终端 2：

```bash
make qemu
```

进入 xv6 后运行 `nettests`。网络实验准备步骤较多，不建议作为答辩首选演示。

## 6. 十个 Lab 的一句话解释

1. `util`：用已有系统调用编写 Unix 用户程序，练习进程、管道和文件操作。
2. `syscall`：增加系统调用跟踪和系统资源统计，理解用户态进入内核的路径。
3. `pgtbl`：操作 RISC-V 页表，理解虚拟地址到物理地址的映射。
4. `traps`：处理系统调用、异常与定时器中断，并实现用户态 alarm。
5. `cow`：让 `fork` 先共享物理页，写入时再复制，减少无用内存拷贝。
6. `thread`：实现用户线程切换，并练习互斥锁和条件变量。
7. `net`：补全 E1000 网卡的发送和接收描述符环。
8. `lock`：拆分热点锁，提高多核内存分配和块缓存的并行度。
9. `fs`：用二级间接块支持大文件，并增加符号链接。
10. `mmap`：把文件惰性映射到进程地址空间，并在共享映射时处理写回。

## 7. 答辩前检查

- 确认 WSL2、Ubuntu、RISC-V GCC 和 QEMU 均能正常启动。
- 提前执行一次 `git switch mmap && make clean && make qemu`。
- 准备 `mmaptest` 的成功输出和一个备用实验。
- 不在答辩前临时升级编译器或 QEMU。
- 不把十个独立实验分支合并成单一分支。
